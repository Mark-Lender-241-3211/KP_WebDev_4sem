# Веб-приложение для учета книг и читателей библиотеки

Курсовой проект по дисциплине «Разработка веб-приложений».

Тема проекта: «Разработка веб-приложения для автоматизации учета книг и читателей библиотеки».

## Описание проекта

Проект представляет собой веб-приложение для небольшой библиотеки. Система предназначена для ведения каталога книг, учета читателей, оформления выдачи и возврата книг, просмотра статистики и выгрузки данных.

Приложение ориентировано на небольшие библиотеки, где требуется простой учет книжного фонда, читателей и операций выдачи без внедрения сложных библиотечных информационных систем.

## Основные возможности

В приложении реализованы:

- регистрация и авторизация пользователей;
- разграничение доступа по ролям;
- каталог книг с поиском, фильтрацией и сортировкой;
- группировка разных изданий одной книги;
- карточка книги с обложкой, описанием, авторами, категориями и доступностью;
- добавление, редактирование и удаление книг библиотекарем;
- загрузка и отображение обложек книг;
- учет читателей;
- карточка читателя с историей выдач;
- редактирование данных читателя библиотекарем;
- оформление выдачи книги;
- возврат книги;
- автоматическое обновление статуса просроченных выдач;
- журнал выдач с поиском, фильтрацией и сортировкой;
- статистика по фонду, читателям, выдачам и категориям;
- выгрузка каталога книг и журнала выдач в CSV;
- административная панель Django для управления пользователями и группами.

## Роли пользователей

В системе используются три роли.

### Читатель

Читатель может:

- зарегистрироваться в системе;
- войти в систему;
- просматривать каталог книг;
- открывать карточки книг.

Читатель не имеет доступа к журналу выдач, статистике, управлению книгами и управлению читателями.

### Библиотекарь

Библиотекарь работает через основной интерфейс приложения и может:

- просматривать каталог книг;
- добавлять, редактировать и удалять книги;
- загружать обложки книг;
- просматривать список читателей;
- открывать карточки читателей;
- редактировать данные читателей;
- оформлять выдачу книг;
- возвращать книги;
- просматривать журнал выдач;
- просматривать статистику;
- выгружать каталог книг и журнал выдач в CSV.

### Администратор

Администратор работает через административную панель Django и управляет:

- учетными записями пользователей;
- группами пользователей;
- правами доступа.

Администратор и библиотекарь разделены логически. В небольшой библиотеке эти обязанности может выполнять один сотрудник, однако в системе роли имеют разное назначение: администратор управляет доступом, а библиотекарь работает с книгами, читателями и выдачами.

## Стек технологий

В проекте используются:

- Python;
- Django;
- SQLite;
- HTML;
- CSS;
- Bootstrap;
- JavaScript;
- PlantUML;
- draw.io;
- LaTeX.

SQLite используется как простая локальная база данных для учебного проекта. Работа с базой выполняется через ORM Django.

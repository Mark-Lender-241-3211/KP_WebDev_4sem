# КП WebDev 4 семестр

Курсовой проект по дисциплине «Разработка веб-приложений».

Тема: «Разработка веб-приложения для автоматизации учета книг и читателей библиотеки».

## Описание проекта

Проект представляет собой веб-приложение для небольшой библиотеки. Приложение должно автоматизировать базовые процессы учета:

- ведение каталога книг;
- учет читателей;
- оформление выдачи и возврата книг;
- поиск, фильтрацию и сортировку записей;
- формирование простой статистики;
- загрузку и выгрузку файлов;
- разграничение доступа по ролям пользователей.

В проекте выделяются три роли:

- читатель;
- библиотекарь;
- администратор.

В небольшой библиотеке администратор и библиотекарь могут быть одним физическим сотрудником, но в системе эти роли разделяются логически: администратор управляет учетными записями и правами доступа, а библиотекарь работает с книгами, читателями и выдачами.

## Планируемый стек технологий

- Python — серверная логика приложения;
- Django — веб-фреймворк;
- SQLite — база данных для простой локальной разработки и развертывания;
- HTML, CSS, JavaScript — пользовательский интерфейс;
- LaTeX — оформление отчета.

SQLite выбран как простой вариант для небольшой библиотеки. При необходимости проект можно будет перенести на PostgreSQL, так как работа с базой данных будет выполняться через ORM Django.

## Назначение папок

### `app/`

Папка для исходного кода веб-приложения. На текущем этапе папка может быть пустой, так как сначала оформляются анализ предметной области и проектирование.

После начала разработки здесь будет размещен Django-проект.

### `docs/`

Папка для проектных материалов, которые не входят напрямую в LaTeX-отчет.

Сейчас здесь хранятся исходники диаграмм и макетов:

- `use_case.puml` — диаграмма вариантов использования;
- `er_diagram.puml` — ER-диаграмма модели данных;
- `catalog_wireframe.drawio` — макет страницы каталога книг;
- `loans_wireframe.drawio` — макет страницы журнала выдач.

### `report/`

Папка с LaTeX-отчетом и файлами оформления.

Основной файл отчета:

```text
report/paper.tex
```

Список источников:

```text
report/refs.bib
```

Изображения, которые вставляются в отчет:

```text
report/images/
```
